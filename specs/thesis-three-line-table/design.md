# 设计说明

## 导航

“毕业论文”保持为可展开目录，其中展示三个素材生成器。选择后进入独立的 `thesis_tools` 页面；中间“文档板块”列同步展示“三线表”“表格”和“多图排版”。

## 数据流

表格工具共用 TSV/CSV 解析、矩形结构校验和 LaTeX 字符转义。同一份二维数据同时驱动网页预览和源码生成；三线表只输出 `booktabs` 结构，普通表格根据选项输出 `tabular`、`tabularx` 或 `longtable`。

多图排版只保留 `File` 对象、浏览器对象 URL、顺序和题注。对象 URL 在删除图片或卸载组件时立即释放；源码使用原始文件名和用户指定的相对目录，不复制或上传文件。

## LaTeX 输出

- 三线表采用 `table`、`tabular` 和 `booktabs`。
- 普通表格采用显式网格边框；通栏模式使用 `tabularx`，跨页模式使用 `longtable` 并重复表头。
- 多图模式使用 `graphicx`，两张及以上图片使用 `subcaption`。
- 表题、图题和标签均为可选字段；界面明确显示所需宏包。

## UI

仅使用项目已有的 shadcn/ui 组件和主题 token。三个工具保持相同的信息层级：标题、左右输入/预览区、下方源码区；窄屏自动堆叠。错误显示在字段附近，生成操作仅在数据有效时可用。

LaTeX 源码区属于结构化源码编辑场景，允许使用项目现有等宽字体工具类；其他界面仍沿用全局字体栈。

## 开源参考边界

LaTeX Table Editor（MIT）用于核对表格类型、表头、对齐和跨页等能力范围，但其 Bootstrap 3、jQuery 技术栈和无公共 API 的结构不适合直接嵌入。本轮生成逻辑保持为小型、可测试的 TypeScript 模块，不新增运行时依赖。
