# 三类过程文档图片接入设计

## 契约

沿用现有公共 `image` 内容块和 TipTap `figureBlock` 适配器。编辑器仍保存仓库拥有的结构化
JSON，图片文件由 Electron 主进程复制到应用私有资源目录。模板渲染器不消费 TipTap JSON
或 HTML。

## 能力门控

`StructuredBodyField` 继续通过 `enableFigures` 控制工具栏。开题报告的研究内容、研究方法、
研究步骤，以及任务书的基本内容、需收集资料传入该能力；中期检查保持现状。每份文档的
图片目录、编号计数和引用目录只扫描本文件允许含图的正文区。

## 开题报告渲染

- 校验器允许三个正文区使用公共 `image` 块，选题意义和参考文献仍为纯段落；
- Word 使用居中图片段落、替代文字、自动图号题注，并设置 `keep_with_next` 与
  `keep_together`；
- LaTeX 将受管图片复制到 bundle，使用不可分页容器和现有图片尺寸令牌渲染；
- 继续拒绝远程 URL、缺失文件、无题注的新图片和失效引用。

## 验证

增加开题报告单图匿名夹具，并扩充桌面端测试，分别检查栏目门控、保存恢复、引用编号、
内容检查和三类导出数据。运行 TypeScript 类型检查、桌面测试、后端契约测试、三类模板
回归和浏览器/Electron 交互检查。Word/WPS 人工验收单独记录。
