# 中期检查目录编号预设需求

## 范围

中期检查目录改为维护“标题 + 层级”，由一个全局编号格式自动生成所有目录编号。首批支持学校写作规范列出的五种格式，并为未来毕业论文目录复用同一规则定义。

历史中期检查数据没有编号格式字段时继续使用已保存的显式编号，不静默重排。

## 用户故事

- 作为学生，我希望选择一种学校允许的目录编号格式，使新增、删除、移动和调整层级后的编号自动保持连续。
- 作为模板维护者，我希望 Word 与 LaTeX 使用同一结构化输入和同一编号规则，避免两个导出结果出现不同编号。
- 作为已有草稿用户，我希望升级后原目录保持不变，直到我主动选择编号预设。

## 验收标准

1. 当用户打开中期检查目录时，系统应提供五种带示例的编号格式。
2. 当用户选择编号格式时，系统应根据目录层级自动生成编号，并将编号显示为只读内容。
3. 当用户新增、删除、移动、增加缩进或减少缩进时，系统应立即重新生成全部编号。
4. 当所选格式最多支持 N 级时，系统应禁止产生超过 N 级的目录。
5. 当文档未记录编号格式时，系统应保留已有显式编号；当用户首次选择格式时，系统才应切换为自动编号。
6. 当导出中期检查时，后端与模板应验证层级不跳级、格式受支持，并按选定格式生成规范编号。
7. 当 Word 和 LaTeX 使用同一输入时，两者应写入完全相同的目录编号文本。
8. 系统不得根据空格、小数点或标题文字猜测目录层级。

## 五种格式

1. `一、` → `（一）` → `1.` → `(1)`（最多 4 级）
2. `第一章` → `一、` → `（一）` → `1.` → `(1)`（最多 5 级）
3. `第一章` → `第一节` → `一、` → `（一）` → `1.` → `(1)`（最多 6 级）
4. `第一篇` → `第一章` → `第一节` → `一、` → `（一）` → `1.`（最多 6 级）
5. `1.` → `1.1` → `1.1.1` → …（最多 6 级）

## 非目标

- 不在中期检查中生成目录页码；页码必须由最终论文排版结果确定。
- 不允许同一份文档混用多种编号格式。
- 不从标题前缀自动推断层级。
