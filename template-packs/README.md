# Template packs

每个可发现模板包是本目录下包含 `manifest.json` 的一级子目录。清单必须声明共享合同版本、
入口点、QA 策略、来源、许可证和每个可加载文件的 SHA-256。运行时应先调用
`validate_pack.py`，只有返回 `trusted: true` 的包才能进入版本选择或渲染。

当前 `sztu-proposal-2026-dev` 是完全合成的开发包，只用于验证合同、发现、兼容性与哈希
门禁。它不是深圳技术大学官方模板，也不代表排版已通过学校、Word 或 WPS 验收。

未经确认可再分发的学校文件、商业字体、签名、印章和私人学生材料只能通过应用的数据目录
作为本地覆盖加载，不得提交到本目录，也不得写入开发包哈希清单。

格式、拒绝规则和命令见 [`FORMAT.md`](FORMAT.md)。
