# 遥测分析工作台

这是一个与桌面应用隔离的本机开发者工具。浏览器只访问本机 Vite 服务；服务端通过已经登录的 CloudBase CLI 执行固定的只读 SQL，不在项目中保存 API Key。

## 启动

在仓库根目录运行 `pnpm telemetry:dev`，然后打开 `http://127.0.0.1:5180`。启动时检查登录状态；登录过期时按页面提示完成 CloudBase 授权，不需要输入查询命令。

需要诊断启动问题时，仍可在仓库根目录运行 `corepack pnpm telemetry:dev`，然后打开 `http://127.0.0.1:5180`。

需要只检查界面时，可以用脱敏模拟数据：

```bash
SZTU_TELEMETRY_DASHBOARD_FIXTURE=1 corepack pnpm telemetry:dev
```

看板执行的 SQL、环境 ID 和时间范围均由服务端固定，不接受浏览器传入 SQL。服务端只返回聚合指标和经过白名单清洗的最近事件；最近事件使用不透明游标分页，每页最多 20 条，不会把安装 ID、会话 ID 或文档内容发送给浏览器。原始遥测仍按云端的 90 天保留策略管理。

“诊断报告”页面支持按报告编号、版本、系统和状态筛选，报告列表每页最多 20 份，单份报告的最近操作每页最多 10 条。点击报告即可查看环境检查、设备档位、服务配置、操作统计和稳定错误码。报告内容仍由本机服务端通过固定只读查询获取，浏览器不能访问 CloudBase 密钥或执行自定义 SQL；诊断报告按云端的 30 天策略自动删除。

“版本发布”页面可以在本机初始化免费的 Ed25519 发布密钥，并通过表单生成包含更新、公告、使用说明和服务状态的签名清单。私钥默认保存在 `~/.sztu-docs-release/`，页面只显示公钥；私钥不会发送给浏览器、CloudBase 或桌面客户端。仅发布公告或服务策略时可以不填写安装包；发布更新时仍需先完成实际打包，再填写其本机绝对路径和最终 HTTPS 下载地址。页面生成文件但不会自动公开，避免一次点击误发布强制更新或停用策略。

同一页面还可为指定学院设置中期检查日期规则。填写学院全称和可选日期的起止边界，点击“生成签名日期规则”只生成本地文件；点击“发布日期规则到云端”则重新签名当前表单并上传到桌面客户端配置的 `midterm_date_policy_url`。发布前需在本机完成 `tcb login`；发布操作不修改更新清单。其他学院不添加规则即可保持原来的日期选择方式。

## 校验

```bash
corepack pnpm telemetry:test
corepack pnpm telemetry:build
```
