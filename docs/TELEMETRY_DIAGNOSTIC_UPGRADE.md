# 学院专业统计与诊断升级

范围：本地源码升级，不打包、不部署。先执行 `20261006090000_accept_diagnostic_reports.sql` 扩展数据库版本约束，再部署包含 diagnostic-context.cjs 的完整云端接收目录，最后发布客户端。接收端兼容旧客户端；新客户端重新确认 1.2 隐私说明后才能发送。

学院、专业从已保存或已载入档案读取，保留目录外的手填名称，仅去除首尾空白；沿用档案字段的 200 字符上限，未填写才记为 unknown。不猜测简称、不强行归类。不会读取并附带姓名、学号、班级和正文等其他字段。管理页按查询区间每个安装标识按事件发生时间选取最后一条记录计数（旧记录缺失发生时间时使用接收时间）；标识每 30 天轮换，不能解释为学生人数。沿用既有 Table/Card 和主题，不新增组件。

诊断使用显式字段和枚举，保持主动创建、预览、发送。新增毫秒耗时与请求关联标识、结构摘要和受限调用位置；不收集正文、异常原文、绝对路径、局部变量。旧诊断仍可读取。

℃ 校验以模板兼容字符规则为准，保留上标、下标和字形样式校验。测试验证隐私边界、协议兼容、分布去重和科学符号回归。界面构建不能代替目标编辑器验收。
