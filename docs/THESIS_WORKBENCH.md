# 毕业论文工作台：首期实施约定

> 当前路线调整：保留侧边栏的毕业论文分组、文档记录和已保存草稿；打开记录后仅展示 LaTeX 模板下载入口。正文编辑与论文预览导出入口暂时收起。模板源码工程仍需整理，下载按钮在确定文件清单并完成验证前保持禁用。下文记录此前的编辑器实现与验证，不代表当前界面仍开放这些操作。

## 基线与隔离

- 软件基线：`589726e`；模板基线：`f0b1e3d`。
- 两个仓库均使用 `codex/thesis-workbench` 分支，软件与 `Thesis` 模板工作树互为同级目录。
- 启动：在软件工作树运行 `pnpm dev:thesis`。使用 5174 端口、工作树自己的 `user-data/thesis-workbench`，三个过程模板明确连接同级模板。
- `node scripts/dev-thesis-workbench.mjs --check` 只检查并显示目录，不启动界面。
- 原软件继续使用原数据及 5173 端口；正式安装版忽略新增开发环境覆盖项。
- 本地 Python 环境暂复用已有 `.venv`，不修改其依赖；后续如需新增依赖，先创建独立虚拟环境。Node 依赖独立安装。

## 用户路径

新建毕业论文 → 在学生档案确认中英文论文题目与基础信息 → 在封面板块填写提交日期 → 填写中英文摘要 → 编排章节和正文 → 插入图表/公式/文献引用 → 预览并修正问题 → 导出 PDF。诚信声明由模板生成，目录由章节标题与页码生成。
普通编辑、保存、编号和编译完全在本地完成，不需要模型调用或 token。

## 界面与数据

- 保持已有 Sidebar / 章节导航 / 正文编辑 / 预览导出 Sheet 结构，不另建布局或 UI 组件库。
- 四类文档共用 `DocumentEditor` 的滚动容器、载入与保存错误提示；毕业论文组件只提供板块内容。参考文献直接使用共用 `ReferenceImporter` 的整高布局和底部统计，不再嵌套独立页面容器；封面日期与中期检查共用日期选择组件。
- 章节树具有稳定 ID，标题层级和排序是语义数据；目录由章节生成，不额外维护。
- 摘要、关键词、章节、参考文献、致谢、附录分别保存；复用现有受限富文本编辑器和图表工具。
- 新增公式节点与稳定的图、表、公式、章节、文献引用节点；插入选择器负责选择目标，编号随排序生成。
- 用结构化工程作为唯一可编辑源。导出的 LaTeX 可独立交给高级用户/Agent 修改，首期不做任意源码改动的反向导入。
- 预览仅由用户触发，复用已保存且与输入及模板指纹一致的 PDF；更改内容或模板后标为过期。
- 中断编译或失败不破坏上一份草稿与有效产物，错误提示定位到具体章节或资源。

## 分阶段交付

1. 工程数据与章节编辑：新增 thesis 文档类型、迁移与校验、保存恢复、章节增删排序、中英文摘要与致谢。
2. 内容与引用：复用图表工具，加入公式和语义引用；稳定 ID、删除被引用项的提示、资源可移植性测试。
3. 导出闭环：以现有 SZTUthesis.cls 为唯一版式引擎，将结构化数据生成内容文件并在可信快照编译；共享预览、取消、错误与字体引导。源码包后续接入。
4. 样例验收：短/正常/长论文、长表与多图、公式与文献、跨章引用；内容、字形、逐页版式和目标编辑器分开记录。

## 首期边界

暂不提供完整毕业论文 Word 导出、任意 Word 的无损导入、所有 LaTeX 宏环境编辑或实时逐字编译。
超出支持范围的内容明确提示，保留原输入，不能静默转换或丢弃。
普通正文从粘贴开始；文献和目录导入复用既有能力。更复杂迁移依据实际样例增加。

## 图表编写阶段

章节正文复用同一个“插入图表”菜单和编辑弹窗。确认后插入当前光标位置，取消保留正文；选中图表可重新编辑、删除，正文撤销/重做适用。单图和组合图使用稳定 ID，所属章由章节树决定，章节移动时重新计算图号；跨章节图片引用保持原目标。表格保留结构化单元格、表题和样式。摘要、致谢和附录仍为文字编辑范围。

图表保存复用既有正文媒体合同的校验，允许论文其他字段未完成。拒绝畸形表格、无效组合图、重复图片 ID 和错误章节归属，失败不会覆盖上一份草稿。素材仍通过现有本机导入与受管图片目录保存，复制文档复用素材，不把临时外部预览 URL 保存为正文。

本轮前端完整测试 292 项通过，构建和 lint 无错误；后台运行 200 项测试（2 项跳过）；覆盖图表保存、重新打开、非法数据保留上一版本。前端覆盖共享图表编辑器、章节切换恢复、移动章节后的图号和引用刷新，以及保留撤销历史。桌面 5174 实例已实际插入合成三线表、自动保存，并在刷新后确认正文和表格恢复；开发样例保留供预览。PDF/LaTeX 编译与图表最终版式验收尚未接入，本轮不代表导出验收。

## 公式与引用编写阶段

- 公式块合同为 `{type: "equation", id, latex}`。稳定 ID 与源码独立保存，编辑保留 ID；按章和正文顺序派生显示编号，不将编号持久化为引用目标。草稿合同保持版本 1 的增量扩展，旧文字/图表草稿无需迁移。
- 正文引用沿用仓库拥有的语义标记约定：`{{cite:BibTeX-key}}` 与 `{{eq:eq-id}}`。编辑器显示不可拆分的引用节点；HTML/编辑器 JSON 仅用于适配，持久化仍为正文合同。
- 文献按正文首次引用顺序编号，文献列表同步排序；未引用条目标注“未引用”。删除文献或公式目标后，保留原引用并显示失效提示。
- 公式当前展示 LaTeX 源码，不执行源码，不承诺语法正确或实际数学排版效果。即时数学预览、源码编译限制、最终 PDF 公式排版由后续渲染阶段完成。
- 本轮后台运行 201 项（2 项跳过）；前端完整回归仅发现原工具栏固定高度断言，修复为只允许论文工具栏自动换行后 App 59 项通过；后续文献排序与编辑器相关 79 项通过。构建与 lint 无错误。桌面实例实际插入公式、公式引用及 BibTeX 文献引用，自动保存后重启并确认恢复。
