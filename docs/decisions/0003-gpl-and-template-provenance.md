# ADR 0003：采用 GPL-3.0 并逐模板记录来源

- 状态：Accepted
- 日期：2026-08-30
- 决策者：项目维护者

## 背景

桌面应用将复用或消费从开源论文模板项目演进的文档能力。同时，官方学校文件、商业字体和学生材料的再分发权不能从应用开源这一事实自动推导。

## 决策

应用仓库整体采用 GNU GPL v3。每个分发的模板包必须单独记录上游仓库、精确提交、修改、文件哈希、版权与许可证。未经确认可再分发的官方 DOCX/PDF、学校印章和字体只能通过本地覆盖机制使用，不得进入源码仓库或 Release。

## 后果

- 构建物需要提供相应源代码、许可证和适当法律声明；
- 依赖与模板包在发布前必须完成许可证清单；
- 新增模板不能只通过功能测试，还必须通过来源与分发审查。

## 验证

发布门禁检查 `LICENSE`、根级 `NOTICE`、第三方许可证清单、模板包 NOTICE、来源提交和哈希；扫描构建物中是否包含未批准字体、私人材料或官方文件。
