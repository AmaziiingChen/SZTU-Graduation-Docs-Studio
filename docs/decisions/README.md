# Architecture Decision Records

本目录保存影响多个模块、发布边界或长期兼容性的架构决策。ADR 一旦被接受，不覆盖原文；后续变化通过新 ADR 标记其被替代。

## 编号与状态

- 文件名：`NNNN-short-title.md`；
- 状态：`Proposed`、`Accepted`、`Superseded`、`Rejected`；
- 每项至少记录背景、决策、后果和验证方式；
- 未经实现和验证的 ADR 只能证明“已决定”，不能证明“已交付”。

新 ADR 从 [0000-record-architecture-decisions.md](0000-record-architecture-decisions.md) 复制。
