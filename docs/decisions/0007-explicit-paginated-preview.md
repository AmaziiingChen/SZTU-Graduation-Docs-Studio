# ADR 0007：一次点击进入与导出一致的分页预览

- 状态：Accepted
- 日期：2026-08-30
- 更新：2026-09-01
- 决策者：项目维护者

## 背景

工作台用于把已经整理好的正文写入正式模板，而不是承担持续写作或正文版本管理。逐字更新的
Markdown 摘要不能回答用户真正关心的问题：当前模板中的分页、表格和字体排版是否可以接受；
同时在每次输入时启动 Word、LaTeX 或 PDF 渲染会造成不必要的资源消耗和状态竞争。

## 决策

分页预览采用用户主动打开的右侧 `Sheet`。点击顶部“预览&导出”后，应用立即打开 `Sheet`；没有当前有效预览时先自动保存并执行内容检查，
再用当前受信任模板快照和正式 PDF 导出实现生成 PDF，以 `pdftoppm` 按 240 DPI 转成逐页 PNG。已有当前有效预览时直接复用，不重复运行渲染管线。
预览运行在临时内存工作区，因此不会创建持久导出任务或写入导出历史。

原始 PDF、分页图和路径只存在于应用私有预览缓存。Electron 主进程限制目录、拒绝符号链接，
并核对文件类型、大小和 SHA-256 后，才把 PNG data URL 交给沙箱 Renderer。每份文档只保留
最近一次成功预览；失败时删除本次不完整缓存。

预览结果绑定文档修订号、规范化输入 SHA-256 和模板快照 SHA-256。正文、共享学生档案或模板
发生变化后，界面立即把旧预览标记为过期；导出预检还会重新比对输入与模板哈希，只有两者
都与当前预览一致时才能执行导出。

预览抽屉使用默认 shadcn `Sheet`、`Alert`、`Button`、`DropdownMenu` 和 `ScrollArea` 组合。宽窗口默认宽度为 512 px，左边缘提供可聚焦、可拖拽的纵向分隔控制；最小宽度为 384 px，最大宽度为当前窗口的 50%，并支持方向键及 `Home`/`End` 调整。分页容器固定为 `210:297` 的 A4 比例并始终适合抽屉宽度；240 DPI 源图在高分屏和放大抽屉时保持可读，图片继续按页延迟解码。窄窗口继续占满可用宽度且不显示拖拽控制。就绪状态只显示分页图，不展示页数、文档类型、缩放控件、重复的自动检查摘要、“当前有效”、模板内部版本、生成时间、重复的可见页码标题或占据预览滚动空间的验收说明。结构和中文字形检查仍由正式预览管线执行，并在统一的“检查与导出”面板中保留独立状态。每次展示当前有效预览时，使用已有 Sonner 信息型 Toast 悬浮提示 PDF 与 Word/WPS 最终显示可能存在差异，且仍需目标编辑器人工验收。过期状态仍以
可操作的 `Alert` 明确提示。shadcn 没有 PDF 页面查看器，原生 `img` 仅用于展示主进程已经验证的
分页 PNG，并以无内边距的边框容器尽量占满抽屉宽度，不建立新的 UI 原语、主题或视觉规范。

分页预览只存在于顶部“预览&导出”打开的右侧 `Sheet` 中，宽窄窗口复用同一个预览组件。导出格式统一从 `Sheet` 固定底部选择，顶部不再保留一个难以解释的独立禁用导出按钮。预检和导出请求必须携带当前预览 ID；后端重新核对文档输入哈希、模板快照哈希、预览清单、路径、大小及 SHA-256。PDF 导出通过这些检查后直接复制已预览的 PDF，不再次运行 XeLaTeX，因此预览对应的 PDF 与导出 PDF 字节一致；DOCX 和 LaTeX 源码包仍按各自正式管线生成。文档板块导航在宽窗口保持固定宽度，在窄窗口替换为紧凑 `Select`，不提供拖拽调宽。环境与质量状态、导出状态和历史通过左侧底部“检查与导出”切换到主内容区，仍复用同一个检查组件。

其中窄窗口文档板块导航策略已由 ADR 0009 替代；预览与导出流程的其余决策保持不变。

## 后果

- 用户形成“填写—预览与检查—直接选择导出格式”的明确闭环；
- 预览和 PDF 导出不会因为使用两套渲染实现而产生版式分歧；
- PDF 导出复用已校验预览产物，避免同一输入二次编译产生文件级差异；
- 修改后的旧预览不能被误当成当前内容，也不能放行导出；
- 预览生成成功只证明当前 PDF 可供审阅，不替代 DOCX 深层结构检查、逐页人工版式检查或
  Word/WPS 目标编辑器验收；
- 预览需要本机 PDF 工具链可用，环境缺失时仍允许继续编辑和自动保存。

## 验证

- 组件测试覆盖未点击时无分页图、首次点击自动生成、有效预览重复打开不重新生成、编辑后自动更新、无有效预览时禁止导出、抽屉内导出、悬浮验收边界提示、A4 比例与固定适合宽度，以及抽屉宽度的拖拽、键盘和 50% 上限；
- 后端集成测试断言 PDF 导出字节与对应预览缓存 PDF 完全一致；
- 后端集成测试使用真实模板生成 DOCX、PDF 和预览分页图，并断言预览不增加导出历史；
- IPC 测试覆盖方法白名单和私有产物返回边界；
- 完整 `pnpm verify` 覆盖 lint、33 项前端测试、110 项 Python 测试和生产构建。
