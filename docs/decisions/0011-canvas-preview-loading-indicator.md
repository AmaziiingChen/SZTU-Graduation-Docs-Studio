# 0011：分页预览生成使用 Canvas 状态动画

## 状态

已接受（2026-09-01）

## 背景

工作台的“预览&导出”需要在保存、检查和分页 PDF 渲染期间显示明确的进行中状态。现有 Lucide 转圈图标能表达忙碌，但无法区分文档正在进行较长的求解/渲染过程。

shadcn/ui 提供 Alert、Button 和 Sheet 等状态容器，但没有可在 React/Electron 中复用、同时具备减少动态偏好与离屏暂停处理的 Canvas 状态动画。

## 决策

引入 MIT 许可的 [`thinking-orbs` 0.3.1](https://github.com/Jakubantalik/thinking-orbs)，仅在分页预览流程中使用：

- 抽屉内“正在保存并检查内容”与“正在生成分页预览”使用 `solving`、64 px 的动画；
- 顶部“预览&导出”按钮在同一流程忙碌时使用 `solving`、20 px 的内联动画；
- 导出、保存、诊断等其他工作流继续保留各自的现有状态反馈。

该依赖使用 Canvas 2D；不访问网络、不引入 WebGL、滤镜或远程资源。组件自带 `prefers-reduced-motion` 静态帧降级、页面隐藏/离屏暂停以及图像语义标签。工作台为每个实例提供具体中文 `aria-label`。

## 后果

- 预览阶段的进行中状态更贴近“文档正在求解和生成”的语义；
- 前端新增一个经用户明确批准的 MIT 依赖，锁定在 `pnpm-lock.yaml`；
- 该动画不构成第二套 UI 系统，也不改变 shadcn 的颜色、排版、容器或交互规范；
- 后续发布仍需在依赖/SBOM 与第三方许可证清单门禁中纳入该依赖。
