# ADR 0000：记录架构决策

- 状态：Accepted
- 日期：2026-08-30
- 决策者：项目维护者

## 背景

桌面安全、模板许可、数据合同和文档验收会跨越多个模块。只把决策保存在对话或代码中会导致边界漂移，也难以向上游和贡献者解释修改原因。

## 决策

使用 Markdown ADR 记录影响多个模块、公开接口、许可证、隐私或发布门禁的决策。接受后的记录保持不可变；改变结论时创建新 ADR，并在双方文件中标注替代关系。

## 后果

- 决策和实现状态可被分别追踪；
- PR 需要链接相关 ADR；
- 小型、局部且可逆的实现细节不强制创建 ADR。

## 验证

每个跨模块 PR 检查是否引用已有 ADR，或解释为何不需要新 ADR。

---

复制本文件创建新 ADR 时，将编号改为下一个顺序号，并填写：背景、候选方案、决策、后果、风险、回滚与验证。
