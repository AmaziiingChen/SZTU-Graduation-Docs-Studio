# ADR 0004：分离文档质量门禁

- 状态：Accepted
- 日期：2026-08-30
- 决策者：项目维护者

## 背景

文本存在、PDF 可渲染、中文字形正确、逐页版式无误和 Word/WPS 实机表现是不同证据。将它们合并成一个“导出成功”状态会误导用户和发布评审。

## 决策

应用、导出回执和验收报告必须分别保存并展示：

1. 内容已提取；
2. 渲染器中文字形有效；
3. 逐页版式已检查；
4. 目标编辑器 Word/WPS 已验证。

自动生成或结构检查不得自动提升人工验收状态。WPS 或 Microsoft Word 是 Office 文档最终验收依据；LibreOffice 仅可用于诊断。

## 后果

- 用户会看到更真实但更细分的质量状态；
- 测试、数据库和 IPC 合同需要支持独立状态及证据引用；
- 发布不能以单一绿色“成功”替代目标编辑器矩阵。

## 验证

合同测试确认状态互不推导；UI 测试确认文案分开；发布证据包含中文提取、150 DPI 以上逐页渲染、CJK 门禁、100% 中文密集页检查和目标编辑器矩阵。
