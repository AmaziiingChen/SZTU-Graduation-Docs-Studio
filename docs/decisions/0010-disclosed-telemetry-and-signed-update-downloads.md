# ADR 0010：明确告知的匿名遥测与签名更新下载

- 状态：Accepted
- 日期：2026-08-31
- 决策者：项目维护者
- 补充：ADR 0001 中“生产环境默认不联网且不采集遥测”的结论

## 背景

项目仍以本机文档处理为核心，但维护者需要了解版本覆盖、粗粒度运行时长、主要功能的成功率和稳定错误码，并在后续发布新版本时让客户端发现和取得更新。学生档案、论文正文、参考文献、模板与导出文件具有明显隐私属性，不能进入远程分析系统。

## 决策

正式构建使用强制但明确披露的匿名运行遥测。首次启动在任何远程请求前展示允许发送与明确禁止发送的字段；使用者只能选择“同意并继续”或退出应用，不提供虚假的关闭开关。开发构建未配置端点时仍展示相同边界，但不会发生外部传输。

遥测只允许版本、平台、架构、30 天轮换的随机安装 UUID、会话 UUID、启动与粗粒度运行时长、页面类型、功能动作结果、稳定错误码和导出格式数量。学生身份、题目、正文、目录、参考文献、路径、文件名、模板内容、哈希、自由文本错误、备注和原始日志一律禁止。

应用启动后立即检查一次版本，此后每 30 分钟发送一次心跳并检查版本。更新清单必须通过内置 Ed25519 公钥验证；下载文件还必须匹配平台、架构、清单大小和 SHA-256。当前只保存已经校验的下载文件并提示使用者，不自动替换应用。

腾讯 COS 只承载公开只读的签名清单和安装包。遥测事件发送到独立 HTTPS 接收端；客户端不得包含 COS SecretId、SecretKey 或清单签名私钥。

## 后果

- 本地文档生成不依赖远程服务；断网或服务端失败不能阻止编辑、检查、预览和导出。
- 发布前必须完成隐私文本、接收端 Schema 校验、限流、原始 IP 日志策略、保留期限和删除流程的审查。
- 遥测合同和客户端都使用封闭允许列表；增加事件或属性必须同时更新合同、说明和回归测试。
- 已校验下载不等于已安装更新。自动替换必须另行完成 macOS/Windows 代码签名、原子安装、重启回滚和跨平台验收。

## 验证

- 未确认前不得入队或上传事件；确认后只发送合同允许的枚举字段。
- Electron renderer 不直接联网；所有远程请求位于受信任主进程。
- 篡改清单、错误签名、平台不匹配、大小不符或 SHA-256 不符均拒绝下载结果。
- 发布构建缺少有效 HTTPS 端点、公钥或签名清单时不得宣称遥测和更新已部署。
