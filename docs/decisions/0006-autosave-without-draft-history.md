# ADR 0006：自动保存当前输入，不建设正文版本管理

- 状态：Accepted
- 日期：2026-08-30
- 决策者：项目维护者

## 背景

工作台不是正文写作工具。用户主要在 Microsoft Word、WPS 或其他本地文档工具中编写并管理正文版本，再将最终或阶段性内容复制到工作台。工作台负责字段写入、结构检查、模板排版和导出。

“恢复上一版”依赖高频自动保存产生的细粒度修订，既不能对应用户理解的 Word 文件版本，也会让工作台看起来承担并不存在的写作版本管理职责。

## 决策

- 删除“恢复上一版”的界面操作和完整 Renderer、preload、IPC、sidecar 协议及后端服务入口。
- 每份文档只保留当前自动保存的输入内容。
- 继续递增文档修订号，但只用于检测过期写入和并发冲突。
- 独立跟踪学生档案与当前文档的修改状态。只修改正文时不得重复写入已经持久化的学生档案；只有对应数据确实变化时才调用其保存接口。
- 保存成功标记必须以各自 IPC 写入完成为准；混合修改允许已成功的档案保存与失败的文档保存分别推进，重试时不重复写入已经成功的部分。
- 保留导出前输入快照和导出历史；它们用于证明某次导出使用了什么输入，不作为正文版本管理。
- 不主动批量删除既有数据库中的旧草稿修订；文档下一次自动保存时，只精确保留新的当前草稿。

## 后果

工作台边界收敛为“输入、检查、排版、导出”。用户自己的 Word/WPS 文件继续作为正文和版本管理的权威来源，同时自动保存仍可避免刷新或关闭应用造成当前输入丢失。独立脏状态减少正文编辑期间不必要的档案序列化、IPC 和 SQLite 事务。
