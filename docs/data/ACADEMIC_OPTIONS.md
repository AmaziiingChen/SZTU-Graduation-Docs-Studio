# 学院、专业与班级选项目录

## 来源与筛选口径

- 来源文件：WhoAreYou 工具本地 `references/深圳技术大学学生标签信息.xlsx`（源工作簿不纳入本仓库）
- 工作表：`深圳技术大学学生标签信息`
- 真实表头：第 3 行；仅读取 `院系`、`年级`、`专业`、`班级` 四列
- 年级范围：严格保留 `2022`、`2023`、`2024`、`2025`
- 生成日期：2026-08-30

源工作表把维度元数据错误地写成了 `A1`，但实际包含 2686 行；目录生成时直接读取工作表 XML 中的真实行。当前源数据在上述范围内有 1971 条完整记录，其中没有 `2024` 年级记录。

## 产物与隐私边界

`apps/desktop/src/data/academic-options.ts` 只保留去重、排序后的学院—专业—班级关系。班级选项会去掉开头的两位或四位年级前缀（例如 `23级`、`2023级`），再在同一学院—专业下合并重复名称。当前共 14 个学院、49 个学院—专业组合和 126 个学院—专业—班级组合。目录不包含姓名、学号、标签、个性化培养方案或任何原始学生行。

更新源工作簿后，应使用相同筛选口径重新聚合，并同时更新目录及其覆盖测试。不得把源工作簿或任何个人记录复制进本仓库。
