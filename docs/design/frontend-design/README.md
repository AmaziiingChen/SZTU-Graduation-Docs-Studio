## 为什么放在仓库里

产品对外页面（下载页、引导页）与桌面端界面共用同一套视觉判断。把技能说明随仓库保存，改动页面时可以直接对照原文，不必联网取用，也方便在评审时指出某条规则被违反。

## 使用方式

设计或重做页面前先读 `SKILL.md`：先定设计方向（颜色、字体、版式、原则），对照它的"AI 默认套路"清单自查一遍，再写代码。它不提供组件或模板，只提供判断标准。
