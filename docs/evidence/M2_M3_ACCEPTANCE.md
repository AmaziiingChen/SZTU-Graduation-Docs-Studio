## 已实现

### 合同与模板包

- `contracts/` 包含学生档案、文档草稿、模板清单、环境状态、检查结果、导出请求、导出回执、QA 策略和 IPC 信封等版本化 JSON Schema。
- IPC 请求 ID 固定为 UUID；请求、成功、错误、进度和取消参数分开定义。
- `template-packs/sztu-proposal-2026-dev/` 是完全合成、GPL-3.0-only、允许公开再分发的开发包；四组 fixture 为 `short`、`normal`、`long`、`layout_stress`。
- 模板发现器拒绝绝对路径、目录遍历、反斜杠、符号链接、未声明文件、重复文件、哈希篡改和不兼容合同版本。
- Python 环境检查调用同一模板发现器，Electron 工作台显示其真实可信状态；自动测试也调用同一实现。

### 本地数据与工作台

- SQLite 使用迁移版本表、外键、唯一键、事务、迁移前备份和失败回滚；持久数据库由 Electron 固定到操作系统应用数据目录。
- 学生档案、文档、有限草稿历史、导出作业/产物、模板安装和设置均有明确表结构。
- 首次保存档案会事务绑定尚未归属档案的活动文档，不会覆盖已经属于其他档案的文档。
- 700 ms 去抖自动保存只有在 sidecar 确认写入后才显示“已保存”；修订号使用乐观并发控制，冲突显示独立状态。
- 临时模式使用内存数据库；显式“丢弃并返回”后关闭内存工作区并恢复持久工作区。
- 工作台支持恢复上一已保存版本，并明确提示 SQLite 本地存储不等于加密。
- renderer 无 Node 能力；preload 只暴露八个显式函数，主进程再次校验 sender、字段、长度、资源 ID、修订号和 JSON 深度。
