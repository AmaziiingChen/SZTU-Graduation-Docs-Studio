# M6 显式分页预览实现与验收记录

- 日期：2026-08-30
- 范围：开题报告与中期检查共用工作台预览基础设施
- 数据：仓库内虚构 `normal.json` fixture；不含真实学生信息

## 实现结果

工作台右侧已从逐字更新的 Markdown 摘要改为用户主动生成的正式分页预览：

1. 用户点击“生成排版预览”；
2. Renderer 先自动保存并执行当前文档内容检查；
3. Python sidecar 在临时内存工作区复用正式 PDF 导出实现；
4. `pdftoppm` 按 150 DPI 生成逐页 PNG；
5. Electron main 在应用私有目录内核对路径、符号链接、类型、大小和 SHA-256；
6. Renderer 只接收核验后的 PNG data URL，并在默认 shadcn 工作台右侧逐页展示；
7. 正文、共享学生档案或模板变化后旧预览过期，输入哈希和模板哈希不匹配时禁止导出。

预览运行不会写入持久导出任务或导出历史。失败的本次缓存会被删除；成功后同一文档只保留
最近一次 UUID 命名的预览缓存。分页图使用原生 `img` 展示，但没有引入 PDF 查看器依赖、
自定义 UI 原语、主题 token 或视觉系统。

## 当前边界

- 预览依赖可用的受信任模板和本机 PDF 工具链；缺失时仍可编辑和自动保存，但不能生成分页预览；
- 预览确认对应当前 PDF 模板快照，不证明 DOCX 在 Word/WPS 中的最终分页；
- Electron 真机端到端截图、键盘/辅助技术检查和 Word/WPS 人工验收仍属于后续独立证据门。
