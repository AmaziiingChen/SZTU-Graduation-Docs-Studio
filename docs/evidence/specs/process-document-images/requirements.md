# 三类过程文档图片接入需求

## 范围

复用中期检查现有结构化图片编辑器，在业务允许的栏目开放单图插入、编辑、编号和引用。
开题报告补齐与任务书、中期检查一致的单图 Word/LaTeX/PDF 渲染能力。组合图继续由已有
模板契约承载，本阶段不新增组合图编辑界面。

## 验收标准

1. 当用户编辑开题报告的研究内容、研究方法或研究步骤时，工作台应显示现有图片工具；
   选题意义和参考文献不得显示图片工具。
2. 当用户编辑任务书的基本内容与要求或需收集资料时，工作台应显示现有图片工具；进度、
   参考文献和选题信息不得显示图片工具。
3. 中期检查研究内容和进展情况应继续保持现有图片功能，不产生回归。
4. 新图片应继续使用受管本机资源、稳定 ID、替代文字、题注、章号、宽度和可选来源键；
   三类文档不得直接读取远程 URL 或依赖原始下载路径。
5. 开题报告 Word 和 LaTeX/PDF 应从同一 `image` 内容块生成图片、自动图号和题注，并保护
   图片与题注的分页关系，不改变官方外层表格和签署区域。
6. 三类文档的草稿保存、重新载入、内容检查、预览和 Word/PDF 导出应保留图片结构与引用。
7. 自动回归通过不得被表述为 Word/WPS 目标编辑器已验收。

## 非目标

- 不增加绘图、裁图或图表数据编辑器；
- 不在受限栏目开放图片；
- 不新增 UI 组件、主题或视觉样式；
- 不修改毕业论文模板。
