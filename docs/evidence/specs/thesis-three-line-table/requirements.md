# 毕业论文素材生成工具需求

## 范围

- 在左侧“毕业论文”目录下提供“三线表生成器”“表格生成器”和“多图排版”三个入口。
- 复用现有工作台结构：左侧应用导航、中间“文档板块”、右侧工具主区域。
- 接受从 Excel、WPS 或文本中粘贴的制表符分隔数据，也接受常见 CSV。
- 在本机完成数据校验、表格预览和 LaTeX `booktabs` 源码生成。
- 提供复制 LaTeX 源码和下载独立 `.tex` 片段的操作。
- 普通表格支持自然宽度、通栏等宽和跨页三种输出，允许设置表头行数和逐列对齐。
- 多图排版支持 1–4 张/行、图片排序、子标题、整组图题和引用标签。

## 验收规则

- 至少包含两列、一个表头行和一个数据行，各行列数必须一致。
- 表头不得为空；最多 12 列、200 行，避免误粘贴超大数据。
- LaTeX 特殊字符必须转义，单元格内容不得直接破坏表格结构。
- 工具不创建毕业论文文档，不接入过程文档的保存、预览和导出状态。
- 表格内容不写入遥测，也不经由 Electron IPC 上传或持久化。
- 图片只通过浏览器对象 URL 在本机预览；离开页面时释放，不写入工作区和遥测。
- 单次多图排版最多读取 12 张图片，避免误选过多文件造成内存压力。

## 明确不做

- 完整毕业论文编辑、编译或导出管线。
- 公式、参考文献、统计图、流程图、字数或论文结构检查工具。
- 图片上传、云端处理或论文素材持久化。
