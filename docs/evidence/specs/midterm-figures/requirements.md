# 中期检查结构化插图需求

## 目标

中期检查正文允许插入本机 PNG/JPEG 图片或图表，并以结构化内容块保存，供同一份数据生成 Word、PDF 预览和 LaTeX bundle。

## 功能需求

1. 用户从正文编辑器工具栏选择图片，应用将文件复制到应用私有资源目录；草稿不得依赖原始下载路径继续存在。
2. 每幅图保存稳定 ID、替代文字、题注、所属章、宽度和可选来源文献键。
3. 图号按正文中的出现顺序、在所属章内自动生成，格式为 `图 X-Y`；移动或新增图片后自动重新编号。
4. 用户可从工具栏插入对某幅图的结构化引用；引用随图号变化，不保存易失效的显示编号。
5. 删除图片后遗留的引用必须显示为失效状态，并在导出检查中阻止静默生成错误引用。
6. 图片与题注在 Word 和 LaTeX 中作为同一版式单元，常规尺寸下不得拆到两页。
7. 仅接收本机 PNG/JPEG，拒绝远程 URL、符号链接、伪造扩展名和超过 20 MiB 的文件。
8. 老草稿中没有稳定 ID 或章号的图片仍可导出，默认按第 1 章编号。

## 非目标

- 本阶段不提供绘图或图表数据编辑能力；图表以图片形式导入。
- 本阶段不实现结构化表格；表题在表上方、跨页续表等规则单独实现。
- 不把真实学生文件、签名、教师意见或图片资源提交到仓库。

## 验收条件

- 前端可插入、编辑和引用图片，保存后重新打开不丢失结构。
- 内容契约、Electron IPC、Word 和 LaTeX 渲染均有回归测试。
- 生成的 Word 结构中图片段落设置 `keep_with_next`，LaTeX 使用不可分页容器承载图片和题注。
- 结构检查能识别重复图 ID、未知图引用和缺失题注。
