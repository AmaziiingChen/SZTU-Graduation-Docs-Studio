## 修复

- 配置遥测地址后默认启动统计，不再以历史告知确认记录作为采集、发送、完成计数的前置条件。没有自动写入同意记录，没有扩大既定采集范围；应用高级诊断区域提供用途说明。该修复同时适用于 Windows/macOS。
- Windows 离线编译环境改为安装到 `%LOCALAPPDATA%/SZTU-Docs-Studio/runtimes/<内容哈希>`，应用仅保存版本定位文件。安装程序单独携带环境文件；相同环境已完成安装时跳过重复写入。编译环境可跨应用升级保留，卸载应用不会清理此缓存。
- 首次安装、从 0.1.8 迁移仍需写入一次编译环境；不能宣称这次迁移无需等待。安装界面展开文件详情，显示首次配置/复用提示。完成标记在最后写入，中断后重跑会重新补齐。
- 环境不在可替换的程序目录内，但应用程序本身仍使用 NSIS 覆盖安装；此修改不提供整个应用的原子升级/自动回退。
- 任务书居中源码原已更新。核对已安装 0.1.8 的 render.py、latex/render.py、word/render.py、python/model.py 与模板仓库一致；0.1.9 延续相同修复。此前报告左对齐时本机仍运行 0.1.6。真实用户样例未读取，无法替代对其具体文档的复核。

2. 检查任务书长标题第二行；重新生成预览，勿把旧导出文件作为新版结果。
3. 在全新 Windows x64 用户环境安装，验证默认遥测、字体提示、预览及导出。
4. 再次运行同一安装包，检查显示复用环境、不再写入全部 TeX 文件。避免强制中止真实安装来测试故障恢复。
