# Windows 0.1.10 长路径修复

2026-10-09。针对新电脑 Administrator 账户安装 0.1.9 时的“无法写入”修复。没有执行安装器或替换本机软件。

## 原因与修复

0.1.9 使用 64 字符哈希作为环境目录名。日志报错的 `tikzlibrarydatavisualization.formats.functions.code.tex` 完整路径达到 265 个 UTF-16 单元，超过传统 Windows 文件路径限制。本机较短用户名和解包检查没有覆盖这一安装路径差异。

0.1.10 使用 `%LOCALAPPDATA%/SZTU-Docs/r/<哈希前16位>`。相同 Administrator 路径缩短至 203 个字符；64 字符中文用户名下为 254 个 UTF-16 单元。完整 64 位哈希仍保存在定位文件及完成标记中，复用前检查完整标记，避免缩短目录名后仅凭前缀认定环境相同。应用和 Python 验证工具同时支持旧 1.0、新 2.0 布局。

构建时扫描所有实际环境文件和目录，分别检查 259/247 字符上限，覆盖 Administrator 与 64 字符中文用户名。NSIS 使用扫描所得目录长度预算检查实际安装位置，超长时在环境解压前明确报错。该检查不表示整个应用升级具备原子回滚能力。
