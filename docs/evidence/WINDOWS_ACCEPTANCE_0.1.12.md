## 使用

新安装版重新导出的论文源码包包含新封面。已经解压的旧论文工程不会被安装包自动覆盖；可从新版源码包更新其中的 `SZTUthesis.cls`，保留自己的 content、参考文献和图片。已有 `supervisortitle` 命令仍能编译，但不再打印；双导师时在 info.tex 添加 `subsupervisor`。

打包与资源校验见 `build-package-offline-0.1.12.log`，校验值保存在 `release/offline/SHA256SUMS-0.1.12.txt`。本轮不修改共享 stable 更新清单。
