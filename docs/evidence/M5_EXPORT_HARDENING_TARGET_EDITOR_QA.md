# M5 导出加固与目标编辑器验收记录

日期：2026-08-30

## 本轮结论

本轮完成开题报告管线的第二阶段加固：受信任模板安装、导出输入快照与脱敏历史、
DOCX 深层结构检查、取消/并发拒绝/覆盖确认、LaTeX bundle 和一个合成正常样例的
macOS Word/WPS 实机验收均已落地。

这是上述功能切片的完成证据，不代表完整 M5/M6、跨平台目标编辑器矩阵、安装包或发布完成。

## 受信任模板安装

- 工作台使用原生文件夹选择器，只向后端传递 `source_directory`。
- 安装器逐文件核验模板引擎和 CJK 验证脚本的固定 SHA-256，拒绝绝对路径逃逸、根目录及
  中间目录符号链接、哈希漂移和已安装版本冲突。
- 受限的学校 DOCX 和验证所需文件只复制到当前用户的私有应用数据目录，不进入源码仓库。
- 同一提交快照连续安装两次均返回 `already_installed`，安装时间保持不变；模板包哈希为
  `c8741e570ceead3ef392315d60892cb46b72556c1679cac7b9ec67d590459827`。

## 快照、历史与导出控制

- 导出任务在运行前保存规范化 JSON 输入快照，并分别记录输入哈希、模板 ID、模板版本、
  模板包哈希、输出哈希和覆盖确认状态。
- 历史接口只返回固定允许字段、文件显示名和 `available`、`missing` 或 `modified` 文件状态；
  不返回正文快照、输出目录或绝对主机路径。文件打开前再次核验数据库记录、路径和哈希。
- 已有目标默认停止；用户明确确认后才覆盖，回执与 artifact 均记录 `replaced_existing`。
- 同一文档已有活动导出时，后端在渲染前返回稳定冲突错误；取消使用当前任务独立的原子标记，
  取消后不保留半成品，并保存最小诊断状态。

## DOCX 深层结构检查

DOCX 检查器把“OOXML 结构通过”和视觉验收分开。自动检查覆盖：

- ZIP/OOXML 可重开、禁止外部关系、A4 页面与页边距；
- 固定章节顺序、目标表格/单元格映射、必填字段和参考文献完整性；
- 粗体、斜体、上标、下标等 run 级语义；
- 学生签名、指导教师意见和学院意见等人工填写区域保持空白。

对应的负向测试分别验证外部关系、错误页边距、章节乱序、富文本不一致和人工区域被填充时
会拒绝通过。自动结构通过不会自动标记 Word/WPS 通过。

## LaTeX bundle 与 PDF 门禁

LaTeX 导出生成确定性的 ZIP bundle，包含 README、bundle manifest、规范化输入 JSON、
数据 TeX 和版本化源码；不包含字体、官方 Office 模板、绝对路径或本机环境信息。README
明确说明应修改 JSON 源后重新生成，不应直接维护生成的 TeX 数据文件。

实际 bundle SHA-256 为
`ed5048eee4964270fb3df29f63d19bd1dbdf04cd7f3f3e4c0e3eacfaf0e8cc9b`。在隔离目录补入本机
合法字体后，XeLaTeX 连续编译两次成功，得到 2 页 A4 PDF；SimSun、SimHei 和 Times 字体
均嵌入。先确认提取文本包含中文，再以 180 DPI 渲染并运行 CJK 门禁，50/50 个采样区域
可见，结果为 100%。两页原始比例检查未见裁切、重叠或人工区域挤压。

## Word/WPS 实机验收

被验收的 DOCX 为合成正常样例，不含真实学生材料；文件 SHA-256 为
`a9876f54afbc934f21dc1b72e9345f1ef7fb77e4421e7061f37aa2a08f1f1991`。

- macOS Microsoft Word：100% 比例逐页检查 2 页，中文、标题、表格、正文和人工签名/意见
  留白可见，未见裁切或重叠。
- macOS WPS Office：100% 比例逐页检查同一文件，观察结果一致。
- 两个目标编辑器检查后再次计算文件哈希，仍与上述哈希相同，未保存编辑器内状态。
- LibreOffice 诊断渲染的 CJK 门禁仅为 14.9%，因此该链路按规则停止视觉结论；它没有被
  用作 Word/WPS 验收，也没有推翻目标编辑器中的实际观察。

数据库中的内容提取、CJK、逐页版式、Microsoft Word 和 WPS Office 状态分别记录，没有
合并为一个“全部通过”。
