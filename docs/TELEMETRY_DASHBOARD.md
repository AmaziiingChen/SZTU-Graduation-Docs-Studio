# 遥测分析工作台

## 定位

遥测分析是独立的本机开发者工作台，不属于面向学生的桌面应用。它使用默认 shadcn/ui Dashboard 结构，仅展示匿名聚合数据，用于回答以下问题：

- 有多少匿名安装和会话正在使用软件；
- 各文档的检查、预览、模板同步、导出和验收是否成功；
- 哪些稳定错误码最常出现；
- 各版本、平台和架构的使用分布；
- 更新检查、发现和下载校验结果。

## 安全边界

- 本机服务端通过已登录的 CloudBase CLI 执行固定只读 SQL，不在项目中保存 `service_role` API Key。
- 浏览器只能选择 7、30 或 90 天范围，不能提交 SQL、表名或环境 ID。
- 浏览器接口不返回安装 ID、会话 ID、原始属性或自由文本。
- 服务端对事件名和属性键再次执行白名单过滤，单次最多读取 50000 条事件。
- PostgreSQL 表不向 `anon` 或 `authenticated` 开放；看板使用单独的服务端密钥读取。

## 指标口径

- 活跃安装：时间范围内不同轮换匿名安装 ID 的数量，不等同于真实人数或设备数。
- 会话数：时间范围内不同匿名会话 ID 的数量。
- 导出成功率：成功导出事件数除以成功、失败和取消的导出尝试总数。
- 失败事件：文档操作结果为 `failure` 的事件数。
- 每日趋势：按 CloudBase `received_at` 日期聚合；不足 8 个日期点时不绘制趋势图。

## 当前限制

真实读取依赖本机 CloudBase CLI 登录态。首次使用运行 `tcb login`；登录过期时重新授权即可，不需要在项目中创建 `.env.local` 密钥文件。
