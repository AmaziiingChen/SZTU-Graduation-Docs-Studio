# 使用说明与演示资料

软件内置一套虚构的演示资料，用来演示过程文档怎么写、怎么引用文献、怎么导出。
演示资料可以随时载入或清除，不会覆盖用户自己的文档。

## 从哪里打开

侧边栏底部的「使用说明」菜单项，或首次启动时页面上方的那条提示（「查看使用说明」）。
使用说明面板里有四步上手说明，以及「载入演示资料」「清除演示资料」两个按钮。

## 包含什么

- 一份学生档案：林知远，202300302001，新材料与新能源学院，新能源材料与工程，
  导师周明远（副教授），2027 届。
- 七类文档各一份：任务书、开题报告、中期检查、指导教师评审表、评阅人评审表、
  答辩记录表、成绩考核表。
- 毕业论文不提供演示样例：论文正文编辑器不在工作台范围内，工作台只提供论文模板
  下载入口；样例数据也不再随包携带。
- 任务书与开题报告带可编辑的 BibTeX 文献来源（三条公开文献）。
- 中期检查包含图片、组合图、三线表、公式和交叉引用。

所有身份和实验数值均为虚构，文献为公开文献。文档标题统一以「参考样例·」开头，
正文保留模拟数据说明。

## 载入与清除的规则

- 载入可以重复执行：已存在的同名样例跳过，只补齐缺少的文档，不会产生重复。
- 如果工作区已有活动档案，演示文档挂在该档案下，不新建档案、不切换当前文档；
  只有工作区空着时才使用样例档案。
- 清除只删除标题以「参考样例·」开头的文档，用户自己写的文档不受影响；
  已删除的样例不会自动重建。
- 写入前会先在临时工作区里逐份校验（建文档、存草稿、走一次导出校验），
  全部通过才写正式库；中途失败不会留下半套资料。

## 自动初始化（沿用旧行为）

全新工作区首次打开时仍会自动装一次演示资料，便于新用户直接看到内容；
之后不再自动重复。已有资料、临时工作区和渲染进程不初始化。

## 源码与检查

样例源文件位于 `backend/src/sztu_docs_backend/sample_data/`，实现位于
`backend/src/sztu_docs_backend/reference_sample.py`。图片按内容哈希存入现有私有
资源目录。协议方法为 `workspace.installReferenceSample` 与
`workspace.removeReferenceSample`。相关检查位于
`backend/tests/test_reference_sample.py`，发布前可用临时 `SZTU_DOCS_DATA_DIR`
验证首次启动，勿清理开发者真实应用数据。
