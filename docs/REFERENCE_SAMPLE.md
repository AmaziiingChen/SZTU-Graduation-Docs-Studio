# 首次启动参考样例

桌面主程序打开持久工作区时，自动初始化一套可直接修改的虚构参考资料：
林知远的学生档案，以及任务书、开题报告和中期检查各一份。没有新增前端入口。
进度安排使用具体起止日期；标题保留语义化上下标；中期检查包含图片、组合图、
三线表、公式和交叉引用；任务书与开题报告保留可编辑的 BibTeX 文献来源。

样例源文件位于 `backend/src/sztu_docs_backend/sample_data/`。身份和实验数值均为
虚构，文献为公开文献。正文保留模拟数据说明，文档名带“参考样例”。

初始化只针对没有学生档案、文档、回收站内容、个人信息草稿或初始化标记的持久
工作区。已有资料与临时工作区跳过；正常重启不会覆盖编辑或重新创建删除的样例。
数据库记录在同一事务中落盘，失败可重试；图片按内容哈希存入现有私有资源目录。

源码运行、Python wheel 和 PyInstaller sidecar 均包含同一份样例数据，Windows
与 macOS 共用该实现。发布前可用临时 `SZTU_DOCS_DATA_DIR` 验证首次启动，勿清理
开发者真实应用数据。相关检查位于 `backend/tests/test_reference_sample.py`。
