SZTU 文档工作台 · 使用说明

任务书、开题报告、中期检查与四类评审表，填写后直接导出可提交的 PDF 或 Word。

下载与更新

下载 Windows 安装包 查看项目主页 正在读取最新版本…
安装包已内置 TeX 引擎、PDF 工具和全部模板字体，纯净 Windows 不需要另外安装任何环境。
0.1.16 及以上版本可以在应用内检查更新；0.2.0 起支持下载后「安装并重启」，自动替换当前版本。

三步上手

  1. 先填档案。打开「档案与基本信息」，填写姓名、学号、学院、专业、班级与指导教师。这些信息会带进之后创建的每一份材料，只填一次。
  2. 再选材料。左侧选择任务书、开题报告或中期检查，点「新建」。按右侧的结构提示逐项填写；正文、列表、三线表、图片、公式都可以在编辑器里完成，保存会自动进行。
  3. 预览后导出。点右上角「预览&导出」，先确认分页与版式，再导出 PDF（推荐）或 Word。预览和导出使用同一套模板，看到的就是最终结果。

毕业论文不做正文编辑：左侧「毕业论文」会默认创建一份记录，点开后下载 LaTeX 模板，在自己的编辑器里排版。模板里已经配好字体、页边距、页眉与参考文献样式，标题支持上下标。

常见问题

第一次打开需要安装 TeX、Poppler 或字体吗？

不需要。安装包已经内置编译引擎、PDF 工具和全部模板字体；首次启动时字体会自动注册到当前 Windows 用户，不需要管理员权限，也不会改动系统字体目录。

预览一直失败怎么办？

先看提示里的原因：缺字段、超页数、图片找不到、文献格式不对，都会指到具体位置。处理后再点「重新生成预览」。如果仍失败：

  • 到「导出记录」里点「查看环境修复指引」，看看是不是安装不完整；
  • 重新运行最新安装包修复（覆盖安装不会删除文档）；
  • 还是不行，就在「导出记录」里点「创建诊断包」→「发送诊断包」。诊断包只在你确认后上传，包含这次操作的文档内容、运行日志和文件路径，维护者可以据此定位问题。

提示缺少字体，或导出的 Word 字形不对？

安装包已内置论文模板和任务书需要的字体。出现缺字体提示时，先重新运行最新安装包，再重启应用。用 Word 打开 DOCX 时，Word 需要本机存在同一个字体名；如果只是自己查看，优先用 PDF，PDF 里的字形已经定稿。

文献检查说没问题，导出却报错？

这是旧版本（0.1.19 及以前）前后端检查规则不一致导致的，0.2.0 已修复：空字段（例如 pages = {}）在导入时就会指出「第几条、哪个字段」，不会等到导出才失败。旧草稿里的参考文献如果还是“段落”格式，导入 BibTeX 后会整份替换为新的文献列表，替换前建议先导出一份 PDF 备份。

点了更新没反应，或者下载失败？

0.1.13–0.1.15 存在下载超时缺陷，基本无法在应用内更新，请直接下载安装包覆盖安装。0.1.16 及以上可以正常下载；0.2.0 起下载完成后会出现「安装并重启」，确认后自动完成替换。安装包尚未做系统代码签名，Windows 可能提示“未知发布者”，按系统提示允许运行即可。

可以装在中文路径下吗？

可以。编译引擎固定在 C:\ProgramData\SZTU-Docs\engine，与安装目录无关；文档、图片与修订记录保存在 %APPDATA%\SZTU文档工作台。升级只替换程序文件，不会搬动或删除你的文档。

我的文档会上传吗？

不会自动上传。文档保存在本机；匿名遥测只包含版本、系统、操作结果和学院/专业，不包含姓名、学号、题目或正文。只有你主动点「发送诊断包」时，诊断材料才会上传，并在云端保留 30 天。

Word 和 PDF 的排版看起来不一样？

Word 和 PDF 由两套渲染器生成，PDF 是最终版式，适合直接提交；Word 便于继续修改，但版式可能随本机 Word 字体与版本浮动。提交前请用 Word 或 WPS 打开检查一遍。

怎么彻底卸载、清除本机数据？

先在 Windows「应用和功能」里卸载程序；如果确认不再需要旧文档，再手动删除 %APPDATA%\SZTU文档工作台（文档、修订、导出记录）和 C:\ProgramData\SZTU-Docs（内置引擎与临时文件）。删除后无法恢复，请先导出需要的文件。

版本与反馈

应用内「导出记录」可以看到每次导出的结果与失败原因。更新通过签名清单分发，发布记录在项目的 docs/evidence 目录。

遇到说明里没有覆盖的问题，欢迎在项目主页提 issue，或把诊断包编号一起发给我们。
